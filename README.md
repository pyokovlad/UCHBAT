## 📖 О сайте

### 🎯 Для кого сделан сайт

Сайт создан для **военнослужащих Учебного батальона** 1-й Московской мотострелковой бригады
сервера **RMRP Кутузовский** (GTA 5 RP) — от стажёров и новобранцев до офицерского состава.

### 🚀 Для чего сделан сайт

Портал решает несколько ключевых задач:

1. **🤖 Автоматизация рутины** — генераторы рапортов, докладов и отчётов
   избавляют от ручного набора текста и снижают количество ошибок
2. **📚 База знаний** — вся информация о службе собрана в одном месте:
   лекции, посты, экзамены, система повышения, баллы
3. **🎓 Обучение новобранцев** — FAQ и структурированные материалы
   помогают быстро влиться в строй
4. **⚡ Экономия времени** — готовые шаблоны объявлений и команд `/todo`
   для быстрого копирования в игру

Сайт состоит из **14 страниц**, разделённых на 4 смысловые группы:

## 💻 Технологии

Сайт написан на **чистом фронтенде** без фреймворков и сборщиков:

- **HTML5** — семантическая разметка
- **CSS3** — стилизация (тёмная военная тема, адаптивность)
- **Vanilla JavaScript** — логика генераторов, поиск, бургер-меню

### Дизайн
- 🌑 Тёмная тема (хаки + золото)
- 📱 Полная адаптивность (ПК, планшет, мобильный)
- 🍔 Бургер-меню на мобильных устройствах
- 🔤 Шрифты: **Oswald** (заголовки) + **Inter** (текст)
